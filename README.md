# Aplikasi Kalkulator BMI

Aplikasi untuk menghitung BMI berdasarkan berat dan tinggi badan menggunakan JavaFX.

### Fitur
- Pilihan jenis kelamin
- Input berat dan tinggi badan
- Menghitung nilai BMI
- Menampilkan kategori BMI

### Teknologi
- Java
- JavaFX
- FXML
- Maven

### Pengembang
Dibuat untuk memenuhi tugas pemrograman Java dengan konsep MVC.
